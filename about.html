01 / About

I’m drawn to machine learning from a systems perspective—not just using models, but understanding what makes them work and how far they can be pushed.

I spend a lot of time experimenting with LLMs and SLMs: running models locally, optimizing inference and memory use, exploring quantization and retrieval, and finding ways to make capable models work within limited hardware.

I’m also fascinated by where software meets the physical world. I like experimenting with hardware controllers, low-level systems, and unconventional ML ideas—taking things apart, learning how they work, optimizing them, and sometimes building my own version to see how far I can push it.
